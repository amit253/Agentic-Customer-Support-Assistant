# Voice Evidence

Step 7 and later scripts write generated TTS output and scrubbed logs here.
Do not place API keys, real customer data, or unreviewed private recordings in
this directory.

`step7-*` and `step8-*` files are the original Step 7/8 evidence and are kept
as history. `final-*` files are the 2026-10-18 reruns of the same scenarios
after the voice pipeline was moved to call setup; see
`docs/voice-coordination.md` ("Final measured runs").
